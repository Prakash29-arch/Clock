# DeskClock: iOS-Clock layout + Nothing dot-matrix style, Android 17 (API 37)

## Look
- **Font** – `res/font/nothing_dot.ttf` ("NDot Clock"): original 5x7 dot-matrix font (generated by
  `tools/make_dotfont.py`, no licence issues). Used for all big time displays (alarm times, world-clock
  times, stopwatch/timer digits, timer keypad, lock-screen alarm, widgets). Small text stays system sans
  because dot fonts are unreadable under ~24sp.
  To use Nothing's real Ndot57 instead, drop your licensed file over `res/font/nothing_dot.ttf`.
- **Black** – window/background `#000000`, cards `#1C1C1E`, separators `#38383A`, accent iOS orange `#FF9F0A`
  (`res/values/colors.xml`, `themes.xml`). Status/nav bars transparent (edge-to-edge).
- **iOS tab bar** – tabs moved from top to a bottom bar (icon over label, orange when selected) with new
  SF-Symbols-style icons (`ic_tab_*_static.xml`). Round action button: green = start, red = stop,
  orange = pause/add (`Utils.tintFab`, stopwatch + timer fragments).
- Expanded alarm rows use a rounded iOS card (`alarm_background_expanded.xml`).

## Widgets (all black, system corner radius, resizable, `previewLayout` + `description`)
| Widget | Class | Style |
|---|---|---|
| Analog clock | `AnalogAppWidgetProvider` | iOS: white numerals, orange sweeping second hand |
| Digital / world clock | `DigitalAppWidgetProvider` | iOS card, dot-matrix time |
| **Nothing clock** | `NothingClockWidgetProvider` | dot-matrix `09:41`, red dot, date, next alarm in red |
| **Nothing analog clock** | `NothingAnalogWidgetProvider` | dotted ring, dotted hands, red second hand |
Dial/hand PNGs are generated by `tools/make_dials.py` into `res/drawable-nodpi`.

## Android 17 / API 37
- `minSdk 31`, `targetSdk 37` (AndroidManifest + `Android.bp`).
- Explicit `android:exported` on every component (required since API 31).
- `FLAG_IMMUTABLE` on all 30 `PendingIntent`s.
- Foreground-service types: `AlarmService` = mediaPlayback; `TimerService` = mediaPlayback|specialUse
  (+ required subtype property). Android 17 only allows background audio from a foreground service.
- Permissions: `USE_EXACT_ALARM` (+ `SCHEDULE_EXACT_ALARM` <=32), `POST_NOTIFICATIONS` (requested at launch),
  `READ_MEDIA_AUDIO`, `FOREGROUND_SERVICE_MEDIA_PLAYBACK/SPECIAL_USE`.
- Predictive back: `enableOnBackInvokedCallback`; `AlarmActivity` blocks back via `OnBackPressedCallback`
  (the old `onBackPressed()` override is not called on API 36+).
- `androidx.activity_activity` added to `static_libs`.
